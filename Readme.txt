In order to run the software, change in Matlab to the main folder and execute the file

> demoeels01.m

In order to change the material properties or sphere diameter, open the file in the editor

> edit demoeels01.m

and modify the code at the beginning of the file.  The software closely follows the nanobem toolbox, see 

L. Huber and U. Hohenester:
A hybrid Maxwell solver for nanophotonics simulations;
Comp. Phys, Commun. 330, 110422 (2026).

U. Hohenester, N. Reichelt, and G. Unger:
Nanophotonic resonance modes with the nanobem toolbox;
Comp. Phys. Commun. 276, 108337 (2022).
